wedda Widget

Wetter für deinen aktuellen Standort auf dem Home- und Sperrbildschirm – Ø aus ICON, GFS und IFS, DWD-Station und DWD-Warnungen.

Scriptable im App Store

  1. Scriptable installieren (kostenlos) und einmal öffnen.
  2. Oben auf „Skript kopieren" tippen.
  3. In Scriptable rechts oben + → ins leere Feld tippen → Einsetzen. Oben den Namen auf wedda ändern, dann Fertig.
  4. Das Skript einmal antippen und Standort erlauben – es erscheint eine Vorschau.
  5. Home-Bildschirm lange drücken → Bearbeiten → Widget hinzufügen → Scriptable → klein oder mittel. Widget antippen → Script: wedda. Das mittlere Widget zeigt 5 Tage und einen Hinweis; für die Stundenansicht bei Parameter „stunden“ eintragen.
  6. Sperrbildschirm: lange drücken → Anpassen → Sperrbildschirm → Widget-Feld → Scriptable → rechteckig oder rund → Script: wedda.
Damit das Widget den Standort auch im Hintergrund findet: Einstellungen → Datenschutz & Sicherheit → Ortungsdienste → Scriptable → „Beim Verwenden der App oder Widgets“. iOS aktualisiert Widgets etwa alle 15–30 Minuten. Ein Tipp aufs Widget öffnet die wedda-App.
